# Retail Sales & Inventory Analytics Dashboard

Interactive retail analytics dashboard built using Streamlit, Plotly, Pandas, and Python.

## Features
- Sales trend analysis
- Revenue tracking
- Inventory monitoring
- Low-stock detection
- Product performance analysis
- Interactive filters

## Tech Stack
- Python
- Streamlit
- Pandas
- NumPy
- Plotly

## Run Locally

```bash
python generate_data.py
streamlit run app.py
